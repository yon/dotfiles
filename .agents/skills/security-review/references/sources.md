# Sources

These primary sources inform the workflow; they are not dependencies to load on every review. Consult current framework and advisory documentation for claims that depend on versions or deployment behavior.

- [OWASP secure code review](https://cheatsheetseries.owasp.org/cheatsheets/Secure_Code_Review_Cheat_Sheet.html): review scope, data flow, and business logic analysis.
- [Anthropic security review agent](https://github.com/anthropics/claude-code-security-review): separate investigation and false-positive filtering. This skill uses contextual validation instead of blanket vulnerability-class exclusions.
- [OpenAI security threat modeling skill](https://github.com/openai/skills/blob/main/skills/.curated/security-threat-model/SKILL.md): repository evidence, assets, attacker capabilities, and explicit trust boundaries.
- [OpenAI security best practices skill](https://github.com/openai/skills/blob/main/skills/.curated/security-best-practices/SKILL.md): select guidance for the actual language and framework, and ground reports in code locations.
